# 3D モデル置き場 (glTF / glb)

**既定は内製（コードで生成した）モデル**です。外部モデルに差し替えたいときだけ、
このフォルダに `models.json` を置いてください（中身は `{}` でも可）。置かれていれば
`<name>.glb` → 無ければ `<name>.gltf` の順に探して読み込みます。

| ファイル名 | 差し替わるもの | 自動スケールの基準 | 置かれる位置 |
|---|---|---|---|
| `room.glb`     | 部屋 (畳・壁・障子・天井) | なし(等倍) | 原点＝部屋の中心・床。6畳 2.73(W) x 3.64(D) m、天井 2.4 m |
| `crt.glb`      | CRT テレビ | **高さ 0.38 m** | テレビ台の天板の上 `(0, 0.4715, -1.52)` |
| `famicom.glb`  | ファミコン本体 | **幅 0.150 m** | 畳の上 `(0.30, 0, -0.90)`、Y回転 -24° |
| `cassette.glb` | カセット | **幅 0.1095 m** | 本体の差込口。傾き(接触不良)アニメの対象 |

## 作るときの約束

- **Y-up / 前面 +Z / 単位はメートル**。Blender なら「+Y Up」でエクスポート。
- **サイズは気にしなくてOK**。上の基準軸に合わせて自動で拡縮し、**底面が置き場所に自動で接地**します（`models.json` で無効にできます）。
- **CRT の画面になるメッシュ名を `screen` にしてください**（大文字小文字は不問。マテリアル名が `screen` でも可）。
  そのメッシュに NTSC/CRT シェーダー（エミュレータ画面＋OSD）が割り当たります。**UV は 0〜1 で画面いっぱいに**張ってください。
  見つからない場合はコンソールに警告が出て、映像は出ません。
- カセットは **Z軸まわりに ±6°** 傾きます。**原点を端子の下端**にしておくと、実機同様「浮いた側から接点が切れる」動きになります。
- `famicom.glb` の中に `cassette` という名前のオブジェクトがあれば、それをカセットとして使います（無ければ別途 `cassette.glb` か仮モデルを載せます）。
- Draco / KTX2 圧縮はローダ未組み込みのため**非対応**です。テクスチャは PNG/JPG を埋め込みで。

## 微調整したいとき: `models.json`

このフォルダに置くと上書きできます（全部省略可）。

```json
{
  "crt": {
    "scale": 1.0,            // 自動スケールをやめて等倍にする
    "autoFit": false,        // 自動スケール自体を切る
    "position": [0, 0.47, -1.52],
    "rotation": [0, 180, 0], // 度。前面が -Z のモデルはこれで回す
    "rotationY": 180,        // Y だけ回すならこちら
    "ground": false,         // 自動接地を切る
    "screenMesh": "Display", // 画面メッシュの名前を指定
    "file": "sony_trinitron.glb"
  },
  "famicom": { "enabled": false }   // 差し替えを使わず仮モデルのままにする
}
```

読み込み結果（採用したファイル名・実寸・画面メッシュ）はブラウザのコンソールに出ます。
